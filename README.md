# Object-Oriented Game Programming (C#)
*Materi Perkuliahan Program Studi Game Application & Technology (GAT) - BINUS University*

Selamat datang di repositori modul pembelajaran **Object-Oriented Game Programming (OOGP)**. Modul ini disusun sebagai panduan praktis bagi mahasiswa **Game Application & Technology (GAT) BINUS University** dalam memahami arsitektur pemrograman game menggunakan bahasa C# murni (.NET Console / Core).

## Pendekatan Pembelajaran
Saat membangun game berskala menengah hingga besar, menulis kode yang sekadar berjalan saja belum cukup. Kita perlu memastikan struktur kode mudah dikembangkan saat fitur bertambah, efisien dalam mengelola memori, serta nyaman dikerjakan bersama tim.

Untuk membantu memahami perbedaan antara kode sederhana dan kode berstandar industri, setiap topik dibahas dengan pendekatan komparatif:

* **Studi Kasus 1: Pendekatan Sederhana / Naive Code**
  Membahas bentuk kode yang umum ditulis di awal belajar, beserta kendala yang biasanya muncul ketika project mulai kompleks (misalnya keterikatan antar-class yang kaku atau potensi penurunan performa).
* **Studi Kasus 2: Penerapan Arsitektur & Best Practices**
  Memperbaiki struktur kode sebelumnya memanfaatkan prinsip OOP, SOLID, dan Game Design Patterns.
* **Analisis & Pembahasan**
  Meninjau alasan teknis di balik perubahan struktur kode dari sudut pandang keterbacaan, fleksibilitas, dan pengelolaan memori.

## Modul Pembelajaran

1. **[Modul 1: Fondasi C# & Konsep OOP Utama](docs/modul-1-fondasi-oop.md)**
   - Encapsulation & C# Properties
   - Inheritance & Polymorphism
   - Abstraction & Interfaces
2. **[Modul 2: Prinsip SOLID dalam Game Programming](docs/modul-2-solid-principles.md)**
   - Single Responsibility Principle (SRP)
   - Open/Closed Principle (OCP)
   - Liskov Substitution Principle (LSP)
   - Interface Segregation Principle (ISP)
   - Dependency Inversion Principle (DIP)
3. **[Modul 3: Fitur Lanjutan C# untuk Game Development](docs/modul-3-fitur-lanjutan-csharp.md)**
   - Generics & Custom Data Structures
   - Delegates, Events, & Action/Func
   - Async/Await & Timer Sederhana
4. **[Modul 4: Game Design Patterns dalam C#](docs/modul-4-game-design-patterns.md)**
   - Singleton Pattern
   - State Pattern (Finite State Machine / FSM)
   - Command Pattern
   - Object Pooling Pattern
   - Observer Pattern
   - Factory Pattern
5. **[Modul 5: Arsitektur Game & Best Practices](docs/modul-5-arsitektur-dan-best-practices.md)**
   - Data-Driven Architecture
   - Composition over Inheritance (Merancang Component System Sendiri)
   - Pengelolaan Memori & Alokasi Garbage Collector
